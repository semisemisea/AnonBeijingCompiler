# 关于编译优化合理性与违规行为认定的说明

为进一步规范全国大学生计算机系统能力大赛编译系统设计赛各赛队的编
译优化合规性与合理性，确保大赛的公平、公正性，全国大学生计算机系统能力
大赛编译系统设计赛技术委员会制定本说明。

一、大赛技术委员会始终提倡正确的编译观，反对投机性优化、猜测性优化
等不当优化手段。
二、合理性优化是指针对代码整体特性进行的通用优化，包括但不限于基于
对基本循环结构的识别进行循环的展开、交换、合并或不变量外提等，或者是利
用处理器硬件通用特性进行指令重排、寄存器分配优化等，或者是不针对特定函
数名或特定调用场景的函数内联等。
三、如果优化策略是基于对特定测试用例的特征（如输入数据或函数名、函
数参数个数及其输入值等）的判断，那么这种优化将被判定为违规行为，具体包
括：
（1）通过识别函数名或特定字符串进行特定优化：编译器匹配函数名或特
定字符串来推测测试用例类型，并进行非通用的特定优化。
（2）对特定测试用例的计算结果进行硬编码：编译器识别特定测试用例中
的某个函数或变量特征，直接返回结果而不进行真实计算。
（3）识别特定测试用例的输入模式并进行特定优化：编译器通过判断输入
数据的特征（如大小、特定字符串）来激活特定优化路径。
（4）利用代码未定义行为：在编译优化中利用代码中未定义行为来获得性
能提升，在其他输入条件下可能导致错误或不一致的结果。
（5）其他通过探测特定输入模式或条件、依赖于特定输入或环境、不能保
证通用情况下正确性的投机性或猜测性优化。
四、本说明未涵盖的情况，以全国大学生计算机系统能力大赛编译系统设计
赛技术委员会的认定为准。如被认定为违规行为，将按照章程和技术方案中的相
关规定进行处理。
