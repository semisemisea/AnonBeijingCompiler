# 编译优化术语表（pass 文档配套）

阅读 `raana_ir/src/opt/passes/` 各模块的中文文档时，遇到不懂的术语查这里。
面向修过中等编译课程、但对本项目术语体系不熟的读者。按主题分组。

## IR 与 SSA 基础

- **SSA（静态单赋值）**：每个值在整个函数里只定义一次。好处：def-use 链直接，
  数据流分析（GVN / IPSCCP 等）变简单。
- **Block 参数（本项目的 Phi）**：SSA 中合并多条汇入路径的值需要 Phi 指令，
  本项目用"目标块的参数"实现：跳转时随边传参，参数 = 每条入边给的值。
- **Inst（指令句柄）**：本项目指令存放在 arena 里，`Inst` 是一个下标句柄，
  不是指针；pass 增删指令不会使其它句柄失效。
- **used_by / def-use 链**：每条指令记录"谁用了我"（used_by）和"我用了谁"
  （操作数）。判断一个值是否被循环外使用 = 查 used_by。

## 控制流（CFG）

- **基本块（BasicBlock）**：单入口、单出口的指令序列，以终结符结尾。
- **终结符（terminator）**：块的最后一条指令，决定控制流去向
  （`jump` 无条件跳 / `branch` 条件分支 / `ret` 返回）。
- **前驱 / 后继（predecessor / successor）**：CFG 边两端的块。
- **支配（dominate）**：块 A 支配块 B ⇔ 从函数入口到 B 的每条路径都经过 A。
  支配是很多变换安全性的基础（如外提的指令仍支配其使用者）。
- **结构边 vs 逻辑边**：结构边是唯一 (源, 目标) 对（图算法用）；逻辑边是一条
  `jump` 或 `branch` 的一条分支臂（带各自的实参向量）。两者数量可以不同——
  branch 两臂指向同一块时，1 条结构边 = 2 条逻辑边。
- **回边（backedge）**：从循环体内指向循环头（header）的边。

## 循环

- **自然循环**：由回边 + 支配关系确定的循环：header 支配所有成员，回边
  指向 header。本项目的循环分析基于这个模型（要求可归约、可嵌套）。
- **header（循环头）**：循环的入口块，回边指向它；它支配循环内所有块。
- **latch（回边块）**：回边所在的块（循环体内最后一个执行、跳回 header 的块）。
- **preheader（前导块）**：循环外唯一能进入 header 的块。很多变换
  （LICM 外提、旋转 guard）需要它作为插入点。
- **continue 边 / exit 边**：header 的两条出边——continue 边目标在循环内
  （进入循环体），exit 边目标在循环外（退出）。
- **嵌套循环**：一个循环的循环体内包含另一个循环。
- **trip count（迭代次数）**：循环体实际执行的次数。
- **严格 exit（strict exit）**：测试形如 `iv < bound`（归纳变量与循环外值
  比较、无副作用）的循环出口；只有这种出口才能精确推导 trip count。
- **归纳变量（IV, induction variable）**：每轮迭代按固定步长变化的变量。
  **基本归纳变量**：直接以 `iv = iv ± const` 形式更新的 IV。
- **test-at-top / test-at-bottom**：循环测试在顶部（`while` 形态：先进去测、
  不通过直接退出）还是底部（`do-while` 形态：先执行一次再测）。旋转 pass
  把前者变后者。

## 优化与 pass 概念

- **pass（优化遍）**：对 IR 做一次变换的单位。本项目 pass 实现 `Pass` trait，
  `run_on` 返回是否改变了 IR。
- **管线（pipeline）**：按序执行的 pass 序列。**initial pass**：只跑一次；
  **fixpoint pass**：整条 fixpoint 段反复执行，直到一轮内没有任何 pass
  改变 IR（最多 100 轮，否则 panic）。
- **固定点（fixpoint）**：上述"跑到不再变化"的收敛状态。
- **强度削减（strength reduction, SR）**：把昂贵运算换成等价廉价运算
  （如乘法换移位）。
- **GVN（全局值编号）**：给表达式编号，相同编号的冗余计算合并。
- **DSE（死存储消除）**：删除不会被读到的 store。
- **DCE（死代码消除）**：删除结果未被使用的指令；DFE 删除不可达函数。
- **LICM（循环不变代码外提）**：把循环内不变的表达式移到 preheader。
- **IPSCCP（过程间稀疏条件常量传播）**：跨函数边界的常量传播 + 分支折叠。
- **TCO（尾调用优化）**：把尾位置的调用改成复用调用者栈帧的跳转。
- **PSR（指针强度削减）**：把循环内的仿射地址计算改写为指针递进。
- **常量折叠 / 常量传播**：编译期直接算出常量表达式结果（折叠），并把常量
  沿 def-use 链代入使用点（传播）。
- **内联（inline）**：在调用点展开被调函数体（有预算控制）。
- **特化（specialization）**：按"常量实参组合"克隆函数，让克隆体内参数恒为
  常量，便于后续传播/折叠。

## 语义（整数运算）

- **向零取整（truncating）**：C / SysY 的整数除法语义——结果向 0 截断，
  如 `-7 / 2 = -3`。
- **算术右移（sar）**：带符号右移，高位补符号位；等价于向 -∞ 取整的除以
  2 的幂。`-7 >> 1 = -4`。
- **逻辑右移（shr）**：无符号右移，高位补 0。
- **掩码（mask）**：用 `x & M` 提取/清除指定位；`~(2^k - 1)` 清除低 k 位。
- **符号位**：最高位（i32 是 `0x8000_0000`）。负数余数/除法的修正序列
  （bias）靠扩散符号位实现。

## 本项目特有

- **Arena（内存池）**：统一分配 IR 对象的存储；`new_local_inst` 等 builder
  接口创建指令，句柄永不失效。
- **RaanaIR / VCode / 汇编**：三层表示——平台无关 SSA IR（`raana_ir`）→
  机器指令级 VCode（`taki_mir`）→ 目标汇编（`anon_armv8` / `uika_riscv`）。
- **TargetPolicy（目标门控）**：AArch64 专属 pass 用 `config.target` 门控，
  RISC-V 管线不注册，防止回归。
- **--pass-stats**：`soyo_compiler` 的 CLI 开关，把各 pass 的统计
  （命中/拒绝/直方图）输出到 stderr，用于语料调查。
- **BodyClonePlan**：`opt/utils/body_clone.rs` 的函数体克隆工具
  （specialize 用它复制整个函数）。
