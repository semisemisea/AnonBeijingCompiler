# ARM Bench Web

ARM Bench 是本地评测控制台。WSL 负责编译、保存测试语料和维护统一 FIFO 队列；
评测板只接收 ELF 与输入并串行执行。

## 数据流

1. 用户选择 Soyo 或 Clang、优化级别、用例和采样参数。
2. 服务端保存任务配置以及用例源码、输入和预期输出。
3. WSL 生成 AArch64 静态 ELF，通过 HTTP 提交至板端队列。
4. `soyo-benchd` 串行执行任务，固定 CPU 并使用 `CLOCK_MONOTONIC_RAW` 计时。
5. 服务端校验输出，保存日志、样本和产物，通过 WebSocket 更新页面。

同一时刻只运行一个用例。上传和请求耗时不计入性能样本；队列查询和终止均由板端
HTTP 接口完成。

## 存储

SQLite 是任务、队列、事件和基准的权威状态源。源码、输入、输出和错误按 SHA-256
内容寻址保存；汇编、ELF 和 Raana IR 保存在任务产物目录。

任务创建后不可修改。重试会复制原任务配置和用例内容，创建一个新的队列任务。

## 界面

页面采用紧凑的双栏布局：左侧显示任务与用例，右侧显示配置、性能历史、输出和产物。
顶部提供板卡状态、当前队列和新建任务入口。任务与用例支持停止、重试、设置基准；已
结束任务可以删除。

性能比较使用正式采样的中位数。只有 `PASS` 结果可以设为基准。
